# x-thumbnail

## the problem

you're building a side project. you need a thumbnail for twitter, linkedin, open graph. photoshop is overkill. canva is slow. you just want something simple and fast.

## the solution

x-thumbnail generates clean, minimalist thumbnails in seconds. no login. no templates. no bullshit.

## how to use

1. enter your title text
2. adjust font size (20-200px)
3. choose grid style (full grid or border only)
4. select export type (twitter/x, open graph, linkedin)
5. download

that's it.

## features

- instant preview
- multiple export formats with correct dimensions
- customizable font sizes
- two grid styles
- clean monospace typography
- free forever

## tech stack

- next.js 16
