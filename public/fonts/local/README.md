# Local card fonts

These files are kept out of git on purpose. The family they come from is licensed separately,
and its licence does not allow the files to be stored in a public repository or served from a
public site.

Drop your licensed files here with these names and they appear in the font picker as
**Sans**, **Mono** and **Semi Mono**. When they're missing, the picker simply hides them.

| File                  | Contents                          |
| --------------------- | --------------------------------- |
| `sans.ttf`            | Sans, variable (wght 100–900)     |
| `mono.ttf`            | Mono, variable (wght 200–900)     |
| `semi-mono-300.otf`   | Semi Mono Light                   |
| `semi-mono-400.otf`   | Semi Mono Regular                 |
| `semi-mono-500.otf`   | Semi Mono Medium                  |
| `semi-mono-600.otf`   | Semi Mono Semibold                |
| `semi-mono-700.otf`   | Semi Mono Bold                    |
| `semi-mono-900.otf`   | Semi Mono Black                   |
